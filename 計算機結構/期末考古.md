# branch prediction
- branch prediction 的錯誤來源
	- branch behavior changes / inherent unpredictability
		```cpp
		for (i=0; i<100; i++)
		// 對迴圈分支而言 : T T T ... T NT
		// => 大部分的時間是 taken, 但最後一次一定會變成 not taken, 造成 misprediction
		```
	- aliasing (又稱 interface/conflict)
		- Branch History Table (BHT) 大小有限
		- 不同 branch 可能使用相同的 index (ex. Branch A $\rightarrow$ Entry 5 ; Branch B $\rightarrow$ Entry 5)
			- 兩個 branch 共用同一個 counter (ex. Branch A often "taken" ; Branch B often "not taken")
			- counter 一直被互相覆蓋 : A 更新 $\rightarrow$ B 更新 $\rightarrow$ A 更新 $\rightarrow$ B 更新 $\rightarrow$ ...
			- 導致準確率下降
		- 通常增加 BHT entries 會提高準確率，因為可以減少 aliasing
			- 但是增對於 inherent unpredictable branch, 加 BHT entries 不行解決
- BHT (Branch History Table)
	- 取 lower bit 當作 index
	- (m, n) correlating predictor
		- m : history
		- n : counter
