# Question
請簡述 Internet Suspend/Resume (ISR) 技術與 Stanford Collective 項目技術的主要功能,方法與目的. VMware 公司開發的 Vmotion 目前有那些限制?
# Answer
根據來源檔案，**Internet Suspend/Resume (ISR)** 技術、**Stanford Collective** 項目以及 **VMware VMotion** 都是關於電腦運算環境遷移（Migration）的技術，以下分別簡述其功能、方法、目的及限制：

1. Internet Suspend/Resume (ISR)

- **主要功能與目的**：旨在讓使用者能在一台機器上「暫停」工作，移動到另一地點後，再透過網際網路從另一台機器「回復」執行。其目的是實現完全的環境行動力，讓使用者不需攜帶電腦也能隨時存取自定義的系統環境。
- **方法**：
    - **封裝（Encapsulation）**：將虛擬機器的狀態（包含記憶體與磁碟內容）封裝成一個檔案。
    - **分散式檔案系統**：將此狀態檔案存放在分散式檔案系統中，使其可透過網路在目的地存取。
    - **提取模型（Pull Model）**：目的地電腦在使用者登入時，根據需求從網路「提取」並加載環境狀態。
    - **Mobile IP**：利用 Mobile IP 技術來維持網路連線的透明性，避免因更換地點而需更動 IP 位址。

2. Stanford Collective 項目

- **主要功能與目的**：與 ISR 類似，目標是將包含作業系統與應用程式的完整「膠囊（Capsule）」遷移至目的地，並致力於提升傳輸效率，使環境遷移能在短時間內（如 20 分鐘的通勤時間）完成。
- **方法**：
    - **推送模型（Push Model）**：將膠囊直接發送至目的地機器。
    - **記憶體氣球技術（Ballooning）**：在客體 OS 中執行「氣球」程式來釋放不必要的記憶體分頁並將其歸零，以壓縮待傳輸的狀態大小。
    - **增量磁碟（Incremental Disks）**：利用寫入時複製（Copy-on-write）與階層架構，僅傳輸與現有膠囊之間的差異，而非完整磁碟映像。
    - **哈希副本（Hashed Copy）**：使用 SHA-1 哈希識別數據塊。若目的地已存在相同哈希值的區塊，則不需重複傳輸，大幅節省頻寬。

3. VMware VMotion 的限制

雖然 VMotion 是商業化的成熟產品，但在來源編寫時仍存在以下限制：

- **伺服器叢集限制**：來源與目的地主機必須位於同一個由 VirtualCenter 管理的伺服器叢集中。
- **共享儲存需求**：兩台主機必須擁有完全相同的檔案系統，且磁碟必須位於**儲存區域網路（SAN）**上的共享磁碟中。
- **硬體一致性**：兩台主機的處理器必須具有相同的架構，且必須由**同一供應商（Vendor）**提供，以避免狀態加載時的相容性問題。
- **應用程式類型**：目前僅限於執行單機（Stand-alone）應用程式，不支援執行多處理器叢集應用程式（Multiprocessor cluster applications）的虛擬機。
- **網路硬體**：需支援 Gigabit 乙太網路轉換器。
